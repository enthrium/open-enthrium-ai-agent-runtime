# Contributing to Open Enthrium AI Agent Runtime

Contributions are welcome. Before opening a PR:

- Open an issue to discuss the change — especially for new features
- Fork the repository and branch from `main`
- Test your changes locally
- Open a PR with a clear description of what and why

Where contributions are most valuable:

- **New SKILL.md skills** — add a folder under [`skills/`](https://github.com/enthrium/open-enthrium-ai-agent-runtime/tree/main/skills) with [`SKILL.md`](https://agentskills.io) + `agent.yaml` + `oe-config.json` (placeholder credentials only)
- **New connector adapters** — contribute to the [platform repo](https://github.com/enthrium/open-enthrium-ai-platform/blob/main/CONTRIBUTING.md); works across Runtime, Platform, and MCP automatically
- **Bug fixes** with clear reproduction steps
